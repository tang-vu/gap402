# Code of Conduct

We follow the spirit of the Contributor Covenant:

- Be respectful, direct, and technical.
- Critique code and ideas, not people.
- Assume good faith; ask before assuming.
- No harassment, discrimination, or personal attacks.
- Security and correctness concerns are always welcome — raise them early.

Maintainers may remove content or contributors who violate these norms.
Report conduct issues through the repository's maintainers.
